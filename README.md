# Hostel-finding-project
HostelFinder is a responsive landing page for a student hostel-finding website. It helps students discover affordable, verified accommodation near campus. The page features a sticky navigation bar with Home, Hostels, About Us, Contact and Login options, plus a full-screen hero section with a background image overlay. Visitors can use the search box to filter hostels by campus area or gate, such as Main Gate, Bishop Tucker, Tech Gate, Bugujju and Kauga, and by room type: single, double or self-contained. Highlights include verified hostels, proximity to campus and free booking support. Built with pure HTML and CSS, it adapts smoothly to mobile screens.
